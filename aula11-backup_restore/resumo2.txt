====================================================
MONGODB - BACKUP E RESTORE
====================================================

REGRA DE OURO

mongodump
MongoDB → BSON

mongorestore
BSON → MongoDB


====================================================
MONGODUMP
====================================================

BACKUP COMPLETO

mongodump
  --db Detran
  --out ./backup_detran


BACKUP DE UMA COLEÇÃO

mongodump
  --db Detran
  --collection veiculos
  --out ./backup_veiculos


BACKUP COM FILTRO

mongodump
  --db Detran
  --collection veiculos
  --query '{"cor":"PRETA"}'
  --out ./backup_veiculos_pretos


BACKUP COMPACTADO

mongodump
  --db Detran
  --archive=backup_detran.archive
  --gzip


BACKUP COM LOGIN

mongodump
  --uri="mongodb://admin:123@localhost:27017/Detran"
  --out ./backup_seguro

====================================================
MONGORESTORE
====================================================

RESTAURAR TUDO

mongorestore
  ./backup_detran


RESTAURAR UMA COLEÇÃO

mongorestore
  --db Detran
  --collection veiculos
  ./backup_veiculos/Detran/veiculos.bson


RESTAURAR APAGANDO DADOS ANTIGOS

mongorestore
  --drop
  ./backup_detran


RESTAURAR ARQUIVO COMPACTADO

mongorestore
  --gzip
  --archive=backup_detran.archive

====================================================
EXERCÍCIOS MAIS COMUNS
====================================================

Backup completo
→ mongodump --db BANCO --out PASTA

Backup coleção
→ mongodump --db BANCO --collection COLECAO --out PASTA

Backup filtrado
→ mongodump --query '{}' ...

Backup compactado
→ mongodump --archive=arquivo.archive --gzip

Restore completo
→ mongorestore PASTA

Restore coleção
→ mongorestore --db BANCO --collection COLECAO arquivo.bson

Restore sobrescrevendo
→ mongorestore --drop PASTA

Restore compactado
→ mongorestore --gzip --archive=arquivo.archive
